# Guide page

## Structure

One left-aligned h1, followed by two sections with h2 labels. The first uses
the admitted prose treatment; the second has a paragraph and CTA. Reuse the
project page's container and rhythm. The guide.vue example implements this
spec and demonstrates a second page generated by composition.

## Content and behavior

The description belongs only in SEO metadata. Each heading identifies its
section. The CTA returns to the home page through NuxtLink. No new visual
vocabulary is needed. Verify navigation, keyboard focus, one h1, no horizontal
overflow, typography and spacing at both target widths.
